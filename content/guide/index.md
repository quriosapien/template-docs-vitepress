# Introduction

This is a template documentation site built with [VitePress](https://vitepress.dev). It's meant to be a starting point for product or project documentation — replace this content with your own.

## What's included

- A home page with a hero section and feature grid (`content/index.md`)
- A guide section with sidebar navigation (`content/guide/`)
- Local full-text search, enabled out of the box
- Nav and sidebar configuration in `.vitepress/config.ts`

## Replacing this content

1. Edit `content/index.md` to update the home page hero and features.
2. Add or edit Markdown files under `content/guide/` (or create new top-level sections) for your own content.
3. Update `nav` and `sidebar` in `.vitepress/config.ts` to match your content structure.
4. Add a logo or other static assets to `content/public/`.

See [Getting Started](./getting-started) to run the site locally.
