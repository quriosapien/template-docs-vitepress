# Getting Started

## Prerequisites

- [Node.js](https://nodejs.org/) 26 or later

## Install dependencies

```sh
npm i
```

## Run the dev server

```sh
npm run docs:dev
```

This starts a local dev server (default: `http://localhost:5173`) with hot reload.

## Build for production

```sh
npm run docs:build
```

Output is written to `.vitepress/dist`.

## Preview the production build

```sh
npm run docs:preview
```
